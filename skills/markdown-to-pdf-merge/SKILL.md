# Markdown 合订本 PDF

## 用途

把若干 Markdown 文件**按给定顺序**合并为单本 PDF：自动生成卷首总纲与三级目录
（篇 / 章 / 节），篇与章带**真实页码**，目录项可点击跳转，表格与代码块保留原样式。
渲染走本机 Chromium 系浏览器（Edge / Chrome）的 headless 打印，不联网、不依赖 LaTeX。

## 何时使用

- 用户要求把多个 `.md` 合并成一个 PDF（合订本 / 手册 / 笔记合集 / 系列文章）。
- 需要中文排版、保留代码块与表格、需要目录。
- 源文档已存在，重点是「拼起来 + 排好版」，而非创作内容。

不适用：需要精确控制分页与页眉页脚的正式出版场景（那时改用 LaTeX / Typst）。

## 快速开始

```bash
python ~/.workbuddy/skills/markdown-to-pdf-merge/scripts/mdmerge_pdf.py \
  -o "D:/out/合订本.pdf" \
  -t "AI 工程师成长手册" -s "Java 工程师转型版 · 合订本" \
  -m "面向 5 年以上 Java 后端工程师" -m "内容快照 2025~2026" \
  "D:/docs/01-入门篇.md" "D:/docs/02-提高篇.md" "D:/docs/03-精通篇.md" \
  "D:/docs/04-词典.md::附录 · AI 名词词典"
```

脚本依次打印：`[engine]` → `[merge]` → `[pass1]` → `[pages]` → `[done]` → `[check]`。
`[check]` 行的「页码偏移 >1 的条目」应为 0。

## 工作流

### 1. 确认输入与顺序

向用户确认（或按文件名自然序推断）**合并顺序**与每篇的显示标题。
标题覆盖语法：`路径::标题`（例如把 `04-词典.md` 显示为「附录 · AI 名词词典」）。

层级约定：每个输入文件 = 一篇；篇内 `## ` = 章（进目录、标页码、章前分页），
`### ` = 节（进目录、不标页码）。文件若无 `# 级标题`，脚本按文件名自动补一个。

### 2. 规划卷首总纲

默认卷首 = 封面（标题 / 副标题 / 说明行 / 徽标）+「总纲」页 + 目录。
需要更丰富的卷首（全书说明、术语约定、案例设定摘录等）时写一个 `front.md`
（内含 `<!--TOC-->` 作为目录占位），用 `--front-md front.md` 传入。

卷首内容优先从源文档**摘录而非创作**；确需新增说明时保持简短，并在交付时说明来源。

### 3. 执行脚本

常用参数：

| 参数 | 作用 |
| --- | --- |
| `-o` | 输出 PDF 路径（必填） |
| `-t / -s / -m / --badge` | 封面标题 / 副标题 / 说明行（可重复）/ 徽标；不给 `-t` 则无封面 |
| `--front-md` | 自定义卷首 markdown（含 `<!--TOC-->`） |
| `--toc-depth {1,2,3}` | 目录深度，默认 3；文档很大时用 2 |
| `--no-page-number` | 目录不标页码（只打一遍，快一半） |
| `--engine edge\|chrome\|绝对路径` | 指定渲染引擎 |
| `--css` | 自定义打印 CSS（默认读 `assets/print.css`） |
| `--build-dir` / `--clean` | 中间产物目录 / 完成后删除 |

依赖（`markdown`、`pypdf`）缺失时脚本自动 `pip install`；
浏览器未找到时报错并提示用 `--engine` 指定。

### 4. 校验产物

按顺序做完这四项再交付：

1. **页码**：`[check] 页码偏移 >1 的条目 0`；`pages.json` 覆盖率应为 100%。
2. **完整性**：用 pypdf 抽取全文，grep 若干关键词——末篇末尾内容、正文里的
   尖括号片段（如 `List<String>`）、代码块首行标注、专有名词，确认没被吞。
3. **目录污染**：确认目录里没有代码块注释（P0 坑）；必要时按
   `references/troubleshooting.md` 的自检片段扫一遍 `merged.md`。
4. **外观**：把 PDF 交给用户预览；要调字体 / 页边距 / 目录密度，改
   `assets/print.css` 后重跑即可，无需改脚本。

### 5. 交付

用 `present_files` 给出 PDF 绝对路径，并说明页数、目录层级、生成脚本位置，
以及中间产物位置（默认 `<out>.build/`）便于二次调整。

## 资源

- `scripts/mdmerge_pdf.py` —— 合并 + 打锚点 + 生成目录 + 两遍打印取页码 + 自检。
- `assets/print.css` —— 默认打印样式（A4、中文字体栈、代码块、表格、封面、目录）。改样式改这里。
- `references/troubleshooting.md` —— 坑位与排查手册（P0/P1/P2 分级）。**遇到问题先读它**。

## 关键机制（改动脚本前必读）

- **两遍打印取页码**：第一遍目录写 3 位占位页码（宽占位保证目录页数不变），打印后
  用 pypdf 定位每个标题所在页，第二遍回填出片。改动目录生成逻辑时必须保持两遍一致。
- **代码围栏内不打锚点**：` ``` ` 内的 `# 注释` 绝不能当标题，否则目录与正文双双被污染。
- **链接降级**：合并后失效的 `*.md` 相对链接，能映射到本篇锚点的转内部链接，
  不能映射的降级为纯文本（保留可读性，不留死链）。
